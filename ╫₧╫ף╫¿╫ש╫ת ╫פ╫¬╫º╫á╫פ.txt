מצב רוח – איך הופכים את האפליקציה לאפליקציה בטלפון
=====================================================
(לעשות יחד עם אבא, לוקח בערך 15 דקות)

מה יש בתיקייה
-------------
index.html             – האפליקציה עצמה
manifest.webmanifest   – אומר לטלפון שזו אפליקציה (שם, צבעים, אייקון)
sw.js                  – מאפשר לאפליקציה להיפתח גם בלי אינטרנט
icon-*.png             – האייקונים של האפליקציה
apple-touch-icon.png   – האייקון לאייפון

שלב 1 – לפני הכל: גיבוי
-----------------------
באפליקציה הנוכחית (בקישור של Claude): לשונית ➕ עוד ← "💾 גיבוי" ← "העתיקי קוד גיבוי".
שלחי את הקוד לעצמך בוואטסאפ. ככה הפלייליסטים לא ילכו לאיבוד.

שלב 2 – להעלות את האפליקציה לאינטרנט (GitHub Pages, חינם)
---------------------------------------------------------
1. נכנסים ל-github.com ומתחברים (אבא פותח חשבון אם אין).
2. למעלה ➕ ← New repository.
3. Repository name: mood-app  ← לסמן Public ← Create repository.
4. בעמוד שנפתח: לוחצים "uploading an existing file".
5. גוררים את כל הקבצים מהתיקייה (לא את התיקייה עצמה!) ← Commit changes.
6. Settings ← Pages (בתפריט בצד).
7. תחת Branch בוחרים main ו-/(root) ← Save.
8. מחכים 1–2 דקות ומרעננים. למעלה תופיע כתובת כמו:
   https://שם-המשתמש.github.io/mood-app/

שלב 3 – להתקין באייפון
----------------------
1. פותחים את הכתובת ב-Safari (לא מתוך וואטסאפ).
2. כפתור השיתוף ⬆️ ← "הוספה למסך הבית" ← הוסף.
3. האייקון של מצב רוח יופיע במסך הבית 🎉

אם אין "הוספה למסך הבית": כנראה שיש הגבלה ב"זמן מסך".
אבא יכול לבדוק ב: הגדרות ← זמן מסך ← הגבלות תוכן ופרטיות.

(באנדרואיד: פותחים ב-Chrome ← ⋮ ← "התקנת אפליקציה" או "הוספה למסך הבית".)

שלב 4 – להחזיר את המידע
-----------------------
באפליקציה החדשה: ➕ עוד ← "💾 גיבוי" ← מדביקים את הקוד ← "שחזרי מהקוד" (פעמיים).

עדכונים בעתיד
-------------
כשמבקשים מ-Claude שינוי באפליקציה, מקבלים index.html חדש.
ב-GitHub: נכנסים ל-mood-app ← Add file ← Upload files ← מעלים את index.html החדש ← Commit.
אחרי דקה-שתיים האפליקציה בטלפון תתעדכן לבד (לפעמים צריך לסגור ולפתוח אותה).
